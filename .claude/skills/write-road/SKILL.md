날짜 기반 학습/기술 기록 문서(Road)를 작성할 때 사용하는 스킬입니다.

## 파일 생성 절차

파일 경로: `apps/blog/src/content/roads/{YYYY}/{MM}/{DD}.mdx`

예시: 2026년 3월 7일 → `apps/blog/src/content/roads/2026/03/07.mdx`

## Frontmatter 템플릿

```md
---
title: ""
date: "YYYY-MM-DD"
---
```

## 문서 작성 컨벤션

기술 개념이나 트러블슈팅을 다음 구조로 작성:

```md
## 개요 / 배경

무엇인지, 왜 등장했는지 설명

## 동작 원리

어떻게 동작하는지 설명 (단계별 또는 항목별)

## 관련 개념 비교 (선택)

유사 개념과의 차이점 비교

## 개념 정리

- "[개념명]이 무엇인가요?" 질문에 대한 2-3분 답변 스크립트

### 핵심 문장

- 핵심만 간결하게 설명하는 30초 버전

## 기타

- 꼬리 질문 예상 및 답변 포인트
```

- `##` (h2)로 섹션 구분
- 코드 예시 포함 가능
- 볼드 기준
  - 볼드 대상은 **핵심 키워드의 첫 등장**과 **각 섹션의 핵심 문장**이다
  - 핵심 문장 강조는 단락·소단락당 최대 1개, 문장 중간의 단어 하나만 굵게 하지 않는다
  - 핵심 문장이 없는 섹션이 없도록 마지막에 섹션별로 점검한다
  - 리스트 항목의 라벨(`**용어**: 설명`), 꼬리 질문의 `**Q. …**`는 구조용으로 허용
  - 괄호·따옴표로 끝나는 볼드 바로 뒤에 조사를 붙이지 않는다 (`**RUM(…)**이라`는 렌더링이 깨지고, `** 이라`로 띄우면 어색하다). 볼드를 빼거나 문장을 바꾼다
- 썸네일 없음 (텍스트 위주)

## 흐름 설명 가이드라인

- 핵심 전달이 우선이다. 단계별 흐름을 단계마다 소제목·코드 블록으로 길게 늘이지 않는다
- 흐름은 **표 하나로 요약**한다 (예: 순서 | 신호 | 알게 된 것)
- 직접 눌러 봐야 이해되는 부분(트레이스 폭포, 전후 비교 등)은 인터랙티브 컴포넌트로 만든다
  - 위치: `apps/blog/src/components/mdx/{Name}.tsx` (React + Tailwind, `not-prose`로 prose 스타일 차단)
  - 사용: MDX 상단에서 import 하고 `<Name client:visible />`로 렌더링
  - 확인: `astro build` 후 데스크톱·모바일(390px) 폭에서 라벨 겹침이 없는지 본다
- 아스키 그림 안에는 한글을 넣지 않는다 (한글 폭이 달라 정렬이 깨진다). 설명이 필요하면 표로 푼다

## 이미지 가이드라인

썸네일 / OG 이미지: 1200 × 630 ⭐ 가장 표준
본문 설명 이미지: 1200 × 675 16:9

### 본문 이미지 영역 구성

이미지는 별도 도구(Codex)로 생성한다. 초안 작성 시에는 이미지를 직접 만들지 않고, 흐름 이해를 돕는 지점마다 **이미지 영역 주석**을 남긴다.

- 위치: 비유가 처음 등장할 때, 여러 단계·구간이 이어지는 흐름, AS-IS/TO-BE 대비, 숫자가 폭발하거나 줄어드는 지점처럼 글만으로는 그림이 잘 안 그려지는 곳
- 개수: h2 섹션당 최대 1개, 글 전체 4~7개
- 형식: MDX 주석으로 남겨 빌드가 깨지지 않게 한다

```mdx
{/* IMAGE: {주제}-{장면}.webp (1200×675) | alt: 이미지가 보여 주는 장면을 한 문장으로 | prompt: 구도(좌우 분할, 위→아래 흐름 등), 등장 사물과 비유, 강조할 지점, 색 의미. 플랫 일러스트, 텍스트 없음. */}
```

- 주석은 **반드시 한 줄**로 쓴다. 여러 줄 주석은 저장 시 Prettier가 `*`를 강조 문법으로 보고 `{/_ _/}`로 바꿔 MDX 파싱 오류가 난다
- 주석은 **리스트·인용문 바깥**의 독립 문단에 둔다 (리스트 항목 사이에 두면 MDX 파싱 오류)
- 개념 글의 색 의미는 글 안에서 일관되게 유지한다 (예: 메트릭=호박, 로그=보라, 트레이스=청록)
- 이미지가 생성되면 주석을 다음으로 교체한다. 파일은 `apps/blog/public/images/roads/`에 둔다

```md
![alt 문장](/images/roads/{주제}-{장면}.webp)
```

## 커밋 컨벤션

글 작성 완료 후 커밋 시 다음 형식을 사용한다.

```
road: {글 제목}
```

예시:

```
road: 서비스 워커(Service Worker)란?
road: React Batching이란?
```
